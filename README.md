# EasyApply

EasyApply is a local AI-powered internship application tracker.

It will:
- Scan internship-related emails from Gmail
- Identify companies and positions
- Determine the current application stage
- Track application status and next steps
- Automatically update a formatted Google Sheet
- Use local machine learning through Ollama to keep the project free

## Planned Stack

- Python
- Ollama
- Gmail API
- Google Sheets API
- SQLite
- Local NLP / embeddings
